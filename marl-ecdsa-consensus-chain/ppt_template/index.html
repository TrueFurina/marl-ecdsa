03 Background & Problem
研究背景与问题

● 协作困境

在多智能体协同任务（如 SimpleSpread 协同导航）中，个体理性智能体倾向于“搭便车”或背叛， 导致全局奖励难以收敛，团队目标达成率低。

● 激励缺失

传统 MARL 仅靠环境奖励塑形，缺乏对“贡献/背叛”的可量化存证， 自私行为难以被识别、归因与惩罚。

● 安全空白

开放网络中智能体身份可被伪造、消息可被篡改，缺乏不可抵赖的 身份签名与防重放机制，协同链路存在信任风险。

● 核心研究问题

能否用 区块链的不可篡改激励 + 密码学身份存证 ，在不破坏 MARL 学习效率的前提下， 持续提升多智能体协作率并抵御自私/伪造攻击？—— 这正是本项目的出发点。

04 Related Work
相关工作

● 多智能体强化学习 (MARL)

  • IQL / VDN / QMIX：值分解与独立学习范式
  • 通信协议（DIAL、CommNet）：隐式共识生成
  • 协作收益分配（Shapley、Credit Assignment）

● 区块链共识

  • PBFT / Tendermint：拜占庭容错经典方案
  • PoS / 贡献加权：以贡献替代算力
  • 联盟链：低延迟、可控节点的工程现实

● 安全签名与身份

  • ECDSA secp256r1：FIPS 186-5 标准曲线
  • RFC 6979：确定性 k 值，杜绝随机性泄露
  • nonce 单调递增 + 时间戳：防重放

● 现有方案的不足

  • MARL 与链上激励多为“离线对账”，缺乏实时双向闭环
  • 共识权重未与 MARL 贡献度对齐
  • 身份层与安全层常分离，难以追责
05 System Overview
系统总览：MARL × 区块链双向协同
06 Module · MARL Layer
核心模块 · MARL 协同层

● 算法：IQL (Independent Q-Learning)

  • 每个智能体独立维护 Q 网络，隐藏维度 128
  • ε-greedy 探索，ε 衰减 5000 步
  • 经验回放 Buffer 2500，Target 网络 τ=0.01

● 环境：SimpleSpread (NumPy)

  • 3 智能体 / 3 目标点，最大步数 25
  • 状态维度 18，观测维度 14，离散动作 5
  • 奖励 = 覆盖目标 − 碰撞惩罚

● 协同—激励接口

每步智能体的动作与状态被 Bridge 采集，作为链上“贡献”的原始证据：

动作序列状态轨迹 合作度评分合规评分 背叛检测

→ 这些信号经签名后上链，成为共识投票权重的依据。

07 Module · Blockchain Layer
核心模块 · 区块链激励层

● 共识算法

CW-PBFT：贡献加权实用拜占庭容错。投票权重来自任务/合作/合规三项贡献， 阈值 ≥ 2/3 权重同意即确认。

● 贡献量化

Shapley 风格权重：task=0.40，coop=0.35，compliance=0.25。 每步结算链上积分，主节点每 10 区块轮换。

● 分级惩罚

警告(10) → 降权(30) → 封禁(50)。 将背叛成本显式写入共识经济，抑制自私行为。

● 身份与存证

每个智能体持有 ECDSA:secp256r1:agent_i 密钥对， 所有上链动作均经 SHA256 + ECDSA 签名，形成不可抵赖的行为存证链；区块头包含前序哈希， 保证整体不可篡改。

09 Security · ECDSA
ECDSA 安全机制

● 密钥与签名标准

  • 曲线：secp256r1 (P-256)，符合 FIPS 186-5
  • k 值：RFC 6979 确定性生成，杜绝随机数泄露
  • 哈希：SHA-256 预处理消息

● 防重放与时效

  • nonce 单调递增，绑定单调递增计数器
  • 时间戳有效期 ±30s，过期签名拒绝上链
  • 每智能体独立密钥，身份不可伪造

● 异常检测

SecurityGuard 对签名进行实时审计：

PASS
安全校验通过
ALERT
k 值重用告警

相同 r 值签名 → 判定私钥可推导风险 → 触发告警/封禁。

16 Security Analysis
安全性分析 · 攻击与防御
攻击面威胁防御机制效果
身份伪造冒充智能体上链ECDSA 密钥签名 + 身份绑定不可伪造
消息篡改篡改动作/状态SHA256 + 签名校验，失败拒收完整性保证
重放攻击复用旧签名单调递增 nonce + 时间戳 ±30s时效拒绝
k 值重用私钥可推导RFC 6979 确定性 k + 告警实时告警
自私背叛拉低团队效用贡献加权共识 + 分级惩罚经济抑制

● 综合结论

密码学身份层 + 经济惩罚层 双重闭环， 使系统在开放、存在自私节点的环境下仍可维持高合作率与可追责性。

17 Conclusion
结论与展望

● 结论

  • 区块链激励使 BC-MARL 环境奖励提升 +29.2%（n=22，方向一致、不显著）
  • 合作率稳定收敛 100%，自私组被有效抑制
  • ECDSA + CW-PBFT 提供身份可信与行为存证

● 创新点

  • MARL ↔ 区块链实时双向协同闭环
  • 贡献加权共识对齐 MARL 行为价值
  • 4 子组件流水线可插拔编排

● 不足

  • 当前 n=3，大规模节点扩展性待验证
  • 示意数据为主，需更多种子复现
  • 实时性在高频步长下开销待优化

● 展望

  • 引入动态贡献权重自适应 λ
  • 拓展至异构智能体与跨链协同
  • 结合轻量级 ZK 证明进一步降信任
