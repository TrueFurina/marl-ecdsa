# V24 主题矢量图标系统说明

本版在 V23 登录注册改造版上统一所有可见的业务图标：侧栏六个栏目、平台标识、工作台指标、登录注册交互、按钮与动态生成内容。

## 新版视觉原则
- 主题色：深青灰 #17282E；操作色 #0D9D91；暖橙 #E99A73；背景 #F7F7F3。
- 图标统一 24×24 视口、1.85 线宽、圆角描边，交互控件一般显示 16–20px。
- 六个导航采用独立语义：总览、训练、贡献治理、可信共识、节点诊断、安全实验，不复用治理奖章表现安全实验。
- 登录注册、工作台共用 `/static/v24-icons.js` 图标字典，页面的关键图标已转为内联 SVG；无外部图标 CDN 或字体依赖。
- 只更改图标与交互呈现，不修改账户、训练、共识和数据库接口。动态渲染的常规操作按钮由轻量脚本添加同系列图标。
- `prefers-reduced-motion: reduce` 下取消图标悬停动画。图标为装饰用途，保留真实按钮文字、aria 标签和键盘操作。

## 关键文件
- `static/v24-icons.css`：统一样式覆盖，需位于其他 CSS 之后。
- `static/v24-icons.js`：本地语义图标字典及动态控件图标同步。
- `templates/dashboard.html` 和 `templates/auth.html`：替换之前不统一的静态 SVG。
- `static/auth.js`：密码可见切换保持图标状态。
- `static/dashboard.js`：去除 Emoji 图标，保持文字信息。
- `static/favicon.ico`、`static/favicon-16.png`、`static/favicon-32.png`、`static/apple-touch-icon.png`：与主题一致的平台标识。

## 在 Windows / VS Code 使用
项目根目录（`source_code`）启动：
```cmd
.venv\Scripts\python.exe start_dashboard.py
```
登录页 `http://127.0.0.1:9090/login`；登录后检查所有侧栏模块及按钮，使用 Ctrl+Shift+R 清除旧样式缓存。

仅覆盖补丁时保留旧工程的 `instance`、`keys`、`results` 等实际业务数据及密钥，不清空数据库。
