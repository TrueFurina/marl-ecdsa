# V21 实验与回归记录

运行环境：本会话的 Linux Python 环境，支持 cryptography、NumPy、PyTorch；缺少 Flask。

## 实际执行

1. 运行 `train.py --mode bc_marl --algorithm iql --n_episodes 3 --n_agents 3 --max_steps 5 --seed 987 --save instance/training_logs/<测试任务ID>.json`，返回退出码 0，生成 3 回合训练 JSON、同任务 ID 的贡献文件。贡献文件新增 `run_tag` 和 `training_result_sha256`；来源绑定服务能够计算出对应投票权重和三个智能体的 BC 积分。此为小规模流水线检查，不是模型收敛实验。
2. 执行 `python -m unittest tests.test_v21_collaboration -v`：2 项通过，含三独立 HTTP 节点共识后回查与篡改后来源验证拒绝。
3. 执行 `python -m unittest tests.test_v12_consensus_invariants tests.test_v11_epoch_view tests.test_v21_collaboration -v`：18 项通过，约 22 秒。
4. `python -m compileall -q visualization train.py marl/analysis/contribution.py` 语法检查通过；`node --check static/v10-consensus.js` 与 `static/v20-integration.js` 通过；HTML DOM ID 唯一性检查通过。
