## 在 Windows 上执行真实联调（请在项目的独立测试副本中运行）
1. 使用 Python 3.11 创建新环境：`py -3.11 -m venv .venv`。
2. 安装依赖：`.venv\Scripts\python.exe -m pip install -r requirements.txt`。
3. 在测试副本中运行：`.venv\Scripts\python.exe scripts\acceptance_v19.py`。
4. 查看 `results/v19_acceptance.json`，其中 PASS 才表示该项目在本机执行通过。
5. 在终端 A 启动 `.venv\Scripts\python.exe run_consensus_nodes.py`。
6. 在终端 B 启动 `.venv\Scripts\python.exe start_dashboard.py`。
7. 浏览器访问 `http://127.0.0.1:9090`，逐页测试登录注册、训练启动停止及日志、贡献预览/激活、交易确认、跨节点核验、节点中断及恢复、安全对照实验，并保存浏览器网络请求与测试截图。
