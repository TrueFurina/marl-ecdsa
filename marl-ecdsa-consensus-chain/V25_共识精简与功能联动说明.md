# V25 共识模块精简与跨模块联动说明

## 本次改动

以 V24 为基础重构「可信共识」页面。现在以**一个已完成的 BC-MARL 训练任务**贯穿各步骤：

1. 协作任务证据链：查看任务来源、贡献记录、纪元版本、区块证据、五阶段状态；
2. 贡献来源与权重治理：从同一任务预览贡献，校验来源摘要；离线激活纪元，查询历史纪元；
3. 多节点共识：显示三节点在线状态、实际票权和区块高度，按高度进行跨节点核验；
4. 签名存证与反向核验：提交当前选中任务对应的有效贡献权重，返回共识复制状态；按区块高度核验签名证书、纪元和训练源文件。

已从页面中移除独立本地单节点交易账本、传统通用区块浏览和交易趋势/出块者图、与训练任务无关的通用文本交易输入框、重复流程介绍/演示卡片。**保留**节点恢复操作，但折叠至高级故障维护区。删除了不再载入的 v8/v15 前端静态资产。后端原有兼容接口仍保留，不会删除历史账户、训练文件、账本和密钥。

## 重点联动修复

- 页面上的 `v22-job` 是贡献预览、纪元激活和链上提交的**唯一训练任务选择控件**，不再存在第二个不同步的任务框。
- 新版前端存证请求携带 `job_id`，后端校验它与当前激活纪元训练绑定一致。若不一致返回 HTTP 400，防止错误来源存证。
- 核验区块时，如该区块对应其他训练任务，页面明确提醒切换至匹配的训练任务。
- 节点诊断默认端口改为 `17401,17402,17403`，对应 V24 的本地三节点共识进程。
- 图表渲染器对已移除的旧版统计 DOM 进行安全跳过；原有协作训练任务管理未受影响。

## 建议使用顺序（CMD）

在 `source_code` 目录中：

```cmd
.venv\Scripts\python.exe start_dashboard.py
```

浏览器访问 `http://127.0.0.1:9090`，登录后完成一次三智能体 BC-MARL 训练。

进入「可信共识」，选择训练任务 → 预览贡献权重；**先停止共识节点**并在安全窗口激活权重纪元，随后另一终端运行：

```cmd
.venv\Scripts\python.exe run_consensus_nodes.py
```

确认节点在线和权重匹配后，点击提交贡献存证，最后按返回区块高度核验历史来源。仅当所有层面验证通过时才能报告完整可信证据闭环。

## 测试和局限

- 21 项多节点共识、纪元、来源绑定、生命周期回归测试全部通过。
- 模拟后端返回真实接口形状的浏览器交互测试在桌面 1440px、平板 768px、手机 390px 通过，JavaScript 页面异常为 0；这属于**模拟接口测试**，不代表实际 Flask + 本地账户数据库的浏览器端到端验收完成。
- 当前环境未安装 Flask，因此完整登录/真实 HTTP E2E 仍需在用户 Windows 环境验收。
- 改版不声称完整 PBFT、贡献分配公平性证明或跨主机生产部署。
